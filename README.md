# homebrew-tap

Homebrew formulae for [dfallman](https://github.com/dfallman)'s tools.

## Usage

```sh
brew tap dfallman/tap
brew install <formula>
```

Or in one step, e.g.:

```sh
brew install dfallman/tap/texttv
```

## Formulae

| Formula | Description |
|---|---|
| [`dan`](https://github.com/dfallman/dan) | Fast, friendly, zero-fuss terminal text editor |
| [`spritz`](https://github.com/dfallman/spritz) | Nano DLNA media server — run in any folder to share it on the LAN |
| [`texttv`](https://github.com/dfallman/texttv) | Render SVT Text-TV (Swedish teletext) pages in the terminal |

Formulae install prebuilt binaries from each project's GitHub releases and are
regenerated automatically by the projects' release workflows.
